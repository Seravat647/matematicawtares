Curso de Cálculo I · Fácil

Classificação de números reais

Classifique cada número como N, Z, Q ou I: 0; −7; √9; √5; π; 0,333...; ³√8.

1

0 é natural (na convenção do livro) e também inteiro e racional: N, Z, Q.

2

−7 é um inteiro negativo, não é natural: Z, Q.

3

√9 = 3, que é inteiro e racional: Z, Q.

4

√5 ≈ 2,236... não é exato, pois 5 não é quadrado perfeito — é irracional: I.

5

π é irracional (transcendente): I. Já 0,333... = 1/3 é uma dízima periódica, portanto racional: Q.

6

³√8 = 2, que é inteiro: Z, Q.

Resultado: 0, √9 = 3 e ³√8 = 2 são inteiros (Z); 0,333... = 1/3 é racional (Q); √5 e π são irracionais (I).
Curso de Cálculo I · Fácil

Inequação do 2º grau

Resolva 2x² − 7x + 3 > 0 e expresse a solução em notação intervalar.

1

Encontramos as raízes com a fórmula de Bhaskara: Δ = 49 − 24 = 25, x = (7 ± 5)/4 → x = 3 ou x = 1/2.

2

Como o coeficiente a = 2 é positivo, a parábola abre para cima, sendo positiva fora do intervalo entre as raízes.

3

Logo, 2x² − 7x + 3 > 0 quando x < 1/2 ou x > 3.

Resultado: S = (−∞, 1/2) ∪ (3, +∞).
Curso de Cálculo I · Fácil

Domínio de função com raiz

Determine o domínio de f(x) = √(4 − x²).

1

Para a raiz existir em R, precisamos que 4 − x² ≥ 0.

2

Isso equivale a x² ≤ 4, ou seja, −2 ≤ x ≤ 2.

Resultado: Dom(f) = [−2, 2].
Curso de Cálculo I · Fácil

Vértice e raízes de função quadrática

Para f(x) = −x² + 4x + 5, determine vértice, raízes e imagem.

1

Raízes: Δ = 16 + 20 = 36, x = (−4 ± 6)/(−2) → x = −1 ou x = 5.

2

Vértice: x_v = −b/2a = −4/(−2) = 2; y_v = f(2) = −4 + 8 + 5 = 9.

3

Como a = −1 < 0, a parábola abre para baixo e o vértice é ponto de máximo.

Resultado: Raízes x = −1 e x = 5; vértice (2, 9); imagem Im(f) = (−∞, 9].
Curso de Cálculo I · Fácil

Limite por fatoração

Calcule lim (x² − 9)/(x − 3) quando x → 3.

1

Substituindo x = 3 diretamente obtemos 0/0 — uma indeterminação que ainda não resolve o limite.

2

Fatoramos o numerador: x² − 9 = (x − 3)(x + 3).

3

Cancelamos o fator comum (x − 3), válido pois x ≠ 3 na definição de limite: a expressão vira x + 3.

4

Substituímos x = 3 na expressão já simplificada.

Resultado: lim = 6.

Nível Médio

Exige combinar duas ou mais ideias, ou uma manipulação algébrica mais cuidadosa.

Curso de Cálculo I · Médio

Inequação irracional

Resolva √(2x − 1) ≤ x − 2.

1

Para a raiz existir, precisamos que 2x − 1 ≥ 0, ou seja, x ≥ 1/2.

2

Como a raiz é sempre ≥ 0, o lado direito também precisa ser ≥ 0: x − 2 ≥ 0, ou seja, x ≥ 2.

3

Elevamos ambos os lados ao quadrado (válido pois ambos são não negativos): 2x − 1 ≤ (x − 2)² = x² − 4x + 4.

4

Reorganizando: x² − 6x + 5 ≥ 0 → (x − 1)(x − 5) ≥ 0 → x ≤ 1 ou x ≥ 5.

5

Intersectando com a restrição x ≥ 2, sobra apenas x ≥ 5.

Resultado: S = [5, +∞).
Curso de Cálculo I · Médio

Reta tangente por derivação implícita

Encontre a reta tangente à curva x² − xy + y² = 3 no ponto (1, 2).

1

Derivamos implicitamente ambos os lados em relação a x: 2x − (y + x·y') + 2y·y' = 0.

2

Isolamos y': y'(2y − x) = y − 2x → y' = (y − 2x)/(2y − x).

3

Substituímos o ponto (1, 2): y' = (2 − 2)/(4 − 1) = 0/3 = 0.

4

A reta tangente tem coeficiente angular 0 e passa por (1, 2): y − 2 = 0·(x − 1).

Resultado: Reta tangente: y = 2.
Curso de Cálculo I · Médio

Limite trigonométrico fundamental

Calcule lim (sen 3x)/x quando x → 0.

1

Reescrevemos multiplicando e dividindo por 3: (sen 3x)/x = 3 · (sen 3x)/(3x).

2

Fazemos a substituição u = 3x; quando x → 0, também u → 0.

3

Usamos o limite fundamental lim (sen u)/u = 1 quando u → 0.

Resultado: lim = 3 · 1 = 3.
Curso de Cálculo I · Médio

Aproximação por linearização

Use a linearização para aproximar √4,02.

1

Escolhemos f(x) = √x e o ponto de referência a = 4, onde f(4) = 2 é fácil de calcular.

2

Calculamos f'(x) = 1/(2√x), logo f'(4) = 1/4.

3

A linearização é L(x) = f(a) + f'(a)(x − a) = 2 + (1/4)(x − 4).

4

Substituímos x = 4,02, ou seja, Δx = 0,02: L(4,02) = 2 + (1/4)(0,02).

Resultado: √4,02 ≈ 2,005.
Curso de Cálculo I · Médio

Extremos absolutos em intervalo fechado

Determine os extremos absolutos de f(x) = 3x⁴ − 4x³ em [0, 3].

1

Derivamos: f'(x) = 12x³ − 12x² = 12x²(x − 1).

2

Pontos críticos: f'(x) = 0 em x = 0 e x = 1 (ambos dentro de [0, 3]).

3

Avaliamos f nos pontos críticos e nas extremidades: f(0) = 0, f(1) = 3 − 4 = −1, f(3) = 243 − 108 = 135.

4

Comparamos os quatro valores para identificar o maior e o menor.

Resultado: Mínimo absoluto f(1) = −1; máximo absoluto f(3) = 135.

Nível Difícil

Demonstrações e problemas de nível avançado, no espírito dos cursos de referência (MIT).

Curso de Cálculo I · Difícil · Nível avançado

Prova de irracionalidade

Prove que √2 + √3 é irracional.

1

Suponha, por absurdo, que √2 + √3 = q, com q racional.

2

Elevamos ao quadrado: 2 + 2√6 + 3 = q² → 2√6 = q² − 5.

3

Como q é racional, q² − 5 também é racional, logo √6 = (q² − 5)/2 seria racional.

4

Mas √6 é irracional (6 não é quadrado perfeito), o que gera uma contradição.

Resultado: Logo, √2 + √3 é irracional. ∎
Curso de Cálculo I · Difícil · Nível avançado

Desigualdade de Bernoulli por indução

Prove que (1+x)ⁿ ≥ 1 + nx para todo x > −1 e n ∈ N.

1

Base (n=1): (1+x)¹ = 1+x = 1 + 1·x — a igualdade vale, confirmando o caso base.

2

Hipótese de indução: suponha (1+x)^k ≥ 1 + kx para algum k ≥ 1.

3

Passo indutivo: como 1+x > 0, multiplicamos ambos os lados por (1+x): (1+x)^(k+1) ≥ (1+kx)(1+x).

4

Expandimos: (1+kx)(1+x) = 1 + (k+1)x + kx² ≥ 1 + (k+1)x, pois kx² ≥ 0.

Resultado: Por indução, (1+x)ⁿ ≥ 1 + nx para todo n ∈ N. ∎
Curso de Cálculo I · Difícil · Nível avançado

Prova rigorosa de limite (ε-δ)

Use a definição ε-δ para provar que lim (3x − 1) = 14 quando x → 5.

1

Dado ε > 0, queremos δ > 0 tal que 0 < |x − 5| < δ implique |(3x−1) − 14| < ε.

2

Simplificamos: |(3x−1) − 14| = |3x − 15| = 3|x − 5|.

3

Queremos 3|x−5| < ε, ou seja, |x−5| < ε/3. Basta escolher δ = ε/3.

4

Verificação: se 0 < |x−5| < δ = ε/3, então |(3x−1)−14| = 3|x−5| < 3·(ε/3) = ε.

Resultado: Para todo ε > 0, δ = ε/3 satisfaz a definição, logo lim (3x−1) = 14 quando x→5. ∎
Curso de Cálculo I · Difícil · Nível avançado

Limite trigonométrico via conjugado

Prove que lim (1 − cos x)/x² = 1/2 quando x → 0.

1

Multiplicamos numerador e denominador pelo conjugado (1 + cos x): (1−cos x)(1+cos x) / [x²(1+cos x)].

2

O numerador vira 1 − cos²x = sen²x (identidade fundamental).

3

Reescrevemos como [sen x / x]² · 1/(1 + cos x).

4

Quando x → 0: lim (sen x/x)² = 1² = 1, e lim 1/(1+cos x) = 1/2.

Resultado: lim (1 − cos x)/x² = 1 · 1/2 = 1/2. ∎
Curso de Cálculo I · Difícil · Nível avançado

Cone de volume máximo inscrito em uma esfera

Um cone é inscrito numa esfera de raio R. Determine as dimensões do cone de volume máximo.

1

Com o centro da esfera na origem e h a altura do cone medida do 'fundo' da esfera, a geometria dá r² = 2Rh − h², para 0 < h < 2R.

2

O volume do cone é V(h) = (π/3)(2Rh² − h³).

3

Derivamos e igualamos a zero: V'(h) = (π/3)(4Rh − 3h²) = 0 → h(4R − 3h) = 0 → h = 4R/3.

4

Verificamos que é máximo e calculamos r² = 2R(4R/3) − (4R/3)² = 8R²/9.

Resultado: h = 4R/3 e r = (2√2/3)R, com volume máximo V = (32/81)πR³.
