Curso de Cálculo II · Fácil

Integração por partes básica

Calcule ∫ x·cos x dx.

1

Aplicamos integração por partes: ∫u dv = uv − ∫v du, escolhendo u = x e dv = cos x dx.

2

Então du = dx e v = sen x.

3

Substituindo: ∫x cos x dx = x sen x − ∫sen x dx.

4

Como ∫sen x dx = −cos x + C.

Resultado: ∫x cos x dx = x sen x + cos x + C.
Curso de Cálculo II · Fácil

Limite de sequência

Determine o limite da sequência aₙ = (2n³ − 1)/(n³ + 4n).

1

Dividimos numerador e denominador pela maior potência de n, que é n³: aₙ = (2 − 1/n³)/(1 + 4/n²).

2

Quando n → ∞, os termos 1/n³ e 4/n² tendem a 0.

Resultado: lim aₙ = 2/1 = 2.
Curso de Cálculo II · Fácil

Soma de série geométrica

Calcule Σ (n=1 a ∞) de 3/4ⁿ.

1

Reescrevemos como série geométrica Σ 3·(1/4)ⁿ, com primeiro termo a₁ = 3/4 e razão r = 1/4.

2

Como |r| < 1, a série converge, com soma S = a₁/(1 − r).

3

Calculamos: S = (3/4)/(1 − 1/4) = (3/4)/(3/4).

Resultado: S = 1.
Curso de Cálculo II · Fácil

Convergência de série alternada (Leibniz)

Verifique se Σ (n=1 a ∞) de (−1)ⁿ/n² converge.

1

Aplicamos o Teste de Leibniz: precisamos que bₙ = 1/n² seja positiva, decrescente e tenda a 0.

2

bₙ = 1/n² é claramente positiva e decrescente para n ≥ 1.

3

lim bₙ = lim 1/n² = 0 quando n → ∞.

Resultado: As três condições são satisfeitas, logo a série converge (na verdade, converge absolutamente).
Curso de Cálculo II · Fácil

EDO separável simples

Resolva y' = x/y, com y(0) = 2.

1

Separamos as variáveis: y dy = x dx.

2

Integramos ambos os lados: y²/2 = x²/2 + C.

3

Aplicamos a condição inicial y(0) = 2: 4/2 = 0 + C → C = 2.

4

Reorganizamos: y² = x² + 4.

Resultado: y = √(x² + 4).

Nível Médio

Exige combinar duas ou mais ideias, ou uma manipulação algébrica mais cuidadosa.

Curso de Cálculo II · Médio

Integração por partes repetida

Calcule ∫ x²·e^(2x) dx.

1

Aplicamos partes com u = x², dv = e^(2x)dx: du = 2x dx, v = (1/2)e^(2x).

2

Primeira aplicação: ∫x²e^(2x)dx = (x²/2)e^(2x) − ∫x e^(2x) dx.

3

Para a integral restante, aplicamos partes novamente: ∫x e^(2x)dx = (x/2)e^(2x) − (1/4)e^(2x).

4

Substituindo de volta: (x²/2)e^(2x) − [(x/2)e^(2x) − (1/4)e^(2x)].

Resultado: ∫x²e^(2x)dx = (x²/2 − x/2 + 1/4)e^(2x) + C.
Curso de Cálculo II · Médio

Potência ímpar de tangente

Calcule ∫ tg⁴x dx.

1

Usamos tg²x = sec²x − 1: tg⁴x = tg²x·sec²x − tg²x.

2

A primeira parcela ∫tg²x sec²x dx se resolve com u = tg x, du = sec²x dx: ∫u² du = u³/3.

3

Para a segunda parcela, usamos de novo tg²x = sec²x − 1: ∫tg²x dx = tg x − x.

4

Juntando: ∫tg⁴x dx = tg³x/3 − (tg x − x).

Resultado: ∫tg⁴x dx = (tg³x)/3 − tg x + x + C.
Curso de Cálculo II · Médio

Raio e intervalo de convergência

Encontre o raio e o intervalo de convergência de Σ (n=0 a ∞) de (−1)ⁿxⁿ/(n+1).

1

Aplicamos o Teste da Razão: L = lim |aₙ₊₁/aₙ| = |x| · lim (n+1)/(n+2) = |x|.

2

A série converge quando L < 1, ou seja, |x| < 1 — raio de convergência R = 1.

3

Em x = 1, a série vira Σ(−1)ⁿ/(n+1), que converge pelo Teste de Leibniz.

4

Em x = −1, a série vira Σ1/(n+1), a série harmônica, que diverge.

Resultado: Raio R = 1; intervalo de convergência (−1, 1].
Curso de Cálculo II · Médio

Lei do resfriamento de Newton

Um café a 90°C é colocado em um ambiente de 20°C. Após 5 min está a 70°C. Quando estará a 40°C?

1

Pela Lei de Newton: T(t) = 20 + 70e^(−kt).

2

Usamos T(5) = 70: 70 = 20 + 70e^(−5k) → e^(−5k) = 5/7 → k = −ln(5/7)/5 ≈ 0,0673.

3

Queremos T(t) = 40: 40 = 20 + 70e^(−kt) → e^(−kt) = 2/7.

4

Isolamos t: t = −ln(2/7)/k = ln(7/2)/k.

Resultado: t ≈ 18,6 minutos.
Curso de Cálculo II · Médio

Equação linear de primeira ordem

Resolva y' − 3y = e^(2x).

1

Fator integrante: μ(x) = e^(∫−3dx) = e^(−3x).

2

Multiplicamos a equação por μ(x): o lado esquerdo vira d/dx[e^(−3x)y] = e^(−x).

3

Integramos ambos os lados: e^(−3x)y = −e^(−x) + C.

4

Isolamos y multiplicando por e^(3x).

Resultado: y = −e^(2x) + Ce^(3x).

Curso de Cálculo II · Difícil · Nível avançado

Fórmula de redução por partes

Prove que ∫ senⁿx dx = −(senⁿ⁻¹x cos x)/n + [(n−1)/n]∫ senⁿ⁻²x dx.

1

Escrevemos senⁿx = senⁿ⁻¹x · sen x e aplicamos partes com u = senⁿ⁻¹x, dv = sen x dx.

2

Isso dá ∫senⁿx dx = −senⁿ⁻¹x cos x + (n−1)∫senⁿ⁻²x cos²x dx.

3

Usamos cos²x = 1 − sen²x: a integral vira (n−1)[∫senⁿ⁻²x dx − ∫senⁿx dx].

4

Passamos o termo (n−1)∫senⁿx dx para o lado esquerdo e agrupamos: n∫senⁿx dx = −senⁿ⁻¹x cos x + (n−1)∫senⁿ⁻²x dx.

5

Dividimos por n para isolar ∫senⁿx dx.

Resultado: ∫senⁿx dx = −(senⁿ⁻¹x cos x)/n + [(n−1)/n]∫senⁿ⁻²x dx. ∎
Curso de Cálculo II · Difícil · MIT

Integral trigonométrica definida com parâmetro (MIT)

Mostre que ∫₀^π x²cos(nx)dx = 2π(−1)ⁿ/n², para n ∈ N*.

1

Aplicamos partes duas vezes: ∫x²cos(nx)dx = x²sen(nx)/n − (2/n)∫x sen(nx)dx.

2

Avaliado de 0 a π, o termo x²sen(nx)/n se anula, pois sen(nπ) = 0.

3

Para ∫x sen(nx)dx aplicamos partes de novo: −x cos(nx)/n + (1/n)∫cos(nx)dx.

4

Avaliando de 0 a π: −π cos(nπ)/n = −π(−1)ⁿ/n, e ∫₀^π cos(nx)dx = 0.

5

Juntando tudo: ∫₀^π x²cos(nx)dx = −(2/n)·[−π(−1)ⁿ/n] = 2π(−1)ⁿ/n².

Resultado: ∫₀^π x²cos(nx)dx = 2π(−1)ⁿ/n². ∎
Curso de Cálculo II · Difícil · Nível avançado

Soma de série via derivação

Calcule Σ (n=1 a ∞) de n/2ⁿ.

1

Partimos da série geométrica Σxⁿ = 1/(1−x), válida para |x| < 1.

2

Derivamos ambos os lados em relação a x: Σ n·xⁿ⁻¹ = 1/(1−x)².

3

Multiplicamos por x: Σ n·xⁿ = x/(1−x)².

4

Substituímos x = 1/2: Σ n/2ⁿ = (1/2)/(1/2)².

Resultado: Σ (n=1 a ∞) n/2ⁿ = 2.
Curso de Cálculo II · Difícil · MIT

Queda com resistência do ar — velocidade terminal (MIT)

Um objeto de massa m cai com resistência do ar F=bv. Resolva mv' = mg − bv e encontre a velocidade terminal.

1

Reescrevemos como v' + (b/m)v = g, uma EDO linear de 1ª ordem.

2

O fator integrante é μ(t) = e^((b/m)t).

3

Integrando: e^((b/m)t)v = (mg/b)e^((b/m)t) + C.

4

Isolando v, com v(0)=0: v(t) = (mg/b)(1 − e^(−bt/m)).

5

Quando t → ∞, o termo exponencial desaparece.

Resultado: Velocidade terminal: v_∞ = mg/b.
Curso de Cálculo II · Difícil · Nível avançado

Solução geral da EDO linear (estrutura y = yₕ + yₚ)

Prove que a solução geral de y' + P(x)y = Q(x) é y = yₕ + yₚ.

1

Seja yₚ uma solução particular fixa: yₚ' + P(x)yₚ = Q(x).

2

Seja y qualquer outra solução da equação completa: y' + P(x)y = Q(x).

3

Subtraindo as duas equações: (y−yₚ)' + P(x)(y−yₚ) = 0, ou seja, w = y−yₚ satisfaz a homogênea.

4

Logo w = yₕ para alguma solução da homogênea, e y = yₚ + yₕ.

Resultado: Toda solução da equação completa se escreve como yₕ + yₚ. ∎
